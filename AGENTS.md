# Lalo Loops Web Landing — Agent Context

**Read this first.** This file gives any AI agent the context needed to work on the Lalo Loops landing page.

---

## What This Project Is

A simple static landing page for [laloloops.com](https://laloloops.com). One `index.html` file with inline CSS, brand images, and links to the Lalo Loops X and GitHub profiles. No frameworks, no build step — just HTML.

The page exists to give Lalo Loops a web presence while the real products are being built. It should be funny, on-brand, and point visitors to X and GitHub.

## Quick Brand Summary

- **What:** Pseudonymous build-in-public brand. One human, tiny AI-agent team, building apps and learning distribution from zero.
- **Tone:** "Serious thesis, unserious delivery." Dry humor, self-aware, technically competent, commercially humbled. Never sounds like an AI hype bro, fake guru, or corporate SaaS announcement.
- **Visual palette:** Warm orange (`#E8872B`), cream (`#FDF0DC`), black (`#1A1A1A`). Cute astronaut-bot characters with infinity symbols.
- **Filter:** Would a real person say this in a group chat with technical friends?

## Git & Commit Rules

### Author

The local git config is set to the project identity. **Always use the local git author for all commits:**

```
Lalo Loops <laloloops@proton.me>
```

### Commit message rules

1. **Never add `Co-Authored-By` trailers.** No co-author lines for Claude, Codex, Copilot, or any AI tool. The commit author is Lalo Loops, period.
2. **Never reference AI tools in commit messages.** No "generated by," "assisted by," or similar attribution in the message body.
3. **Use conventional, human-sounding commit messages.** Short subject line (imperative mood), optional body explaining why. Write like a developer, not a bot.
4. **Do not sign commits** (`--no-gpg-sign` is fine if GPG is configured globally).

### GitHub CLI

Use the `ghl` shell wrapper for all GitHub CLI operations scoped to the LaloLoops account:

```bash
ghl repo view
ghl pr create ...
```

This runs `gh` authenticated as the `LaloLoops` GitHub account without changing the default `gh` auth.

### Repository

- **Remote:** `https://github.com/LaloLoops/laloloops-web-landing` (public)
- **Branch:** `main`
- **Do not force push** unless explicitly asked. The history has already been cleaned once.

## Key Rules

1. **Read the branding repo before making design or copy changes.** Especially `brand/voice_guide.md`.
2. **Keep it simple.** This is a single HTML file. No build tools, no JavaScript frameworks, no npm.
3. **Respect the visual identity.** Stick to the orange/cream/black palette and existing assets.
4. **Commits are by Lalo Loops only.** No AI co-author attribution of any kind.
5. **Use `ghl` for GitHub CLI operations.** Never use bare `gh` for this project.
6. **Protect privacy.** Never add content that reveals the person behind Lalo — no employer, real name, location, or family details.
7. **This is a public repository.** Never commit files containing personally identifiable information (PII), personal references, sensitive data, API keys, credentials, or anything that could de-anonymize the person behind Lalo Loops. Audit every file before committing.
