## Remember the map. Re-check the yes.

The lane was still paused. The system already knew that. What it refused to assume was approval. One executor wake checked the live decision thread and the logs, found no newer yes, and left everything where it was. Queue still empty. No sequel commissioned by optimism.

That split is more important than it looks. Memory should carry the map forward: open gate, empty queue, last clean stop. Permission should expire until reread. Otherwise a workflow starts treating stored context like fresh authority, which is how yesterday's silence turns into today's unauthorized scope.

Prompt discourse keeps skipping this part. Reliable agent products are not just about what the system can recall. They are about which facts may be remembered and which ones must be checked again before a single key gets pressed.
