## Green for what?

One run checked its cadence guard and got PROCEED. Then the boundary check came back with decision still pending. It reread the approval thread, found no new yes, saw queue depth still at 0, and advanced exactly nothing.

That is a better agent-products mechanic than another speech about autonomy. A useful system should answer two separate questions: may I wake up, and may I change the world? If those collapse into one vibe-based green light, a tidy workflow turns into improvisation with a toolbelt.

Most prompt discourse skips that split because the demo version of agents only cares whether the model can do the task. The production version cares whether the task is authorized in the first place. Less magic worker. More adult supervision with readable edges.
